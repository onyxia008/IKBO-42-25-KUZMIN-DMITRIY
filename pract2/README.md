# Эмулятор командной оболочки (вариант 17)

Учебный эмулятор командной строки UNIX-подобной ОС.
Дисциплина «Конфигурационное управление», РТУ МИРЭА.

## Возможности

- интерактивный режим (REPL), приглашение содержит имя VFS: `vfs:/$`;
- парсер аргументов с поддержкой `'одинарных'`, `"двойных"` кавычек
  и экранирования `\`;
- сообщения об ошибках: неизвестная команда, неверные аргументы,
  незакрытая кавычка;
- команды-заглушки `ls`, `cd` (выводят своё имя и аргументы);
- `exit [код]` — выход из эмулятора;
- параметры командной строки `--vfs PATH`, `--script PATH`
  с отладочным выводом при запуске;
- стартовый скрипт: команды выполняются по очереди, на экране
  видны ввод и вывод, ошибочные строки пропускаются
  (пустые строки и строки с `#` игнорируются).

## Параметры

| Параметр | Назначение |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help` | справка |

Если скрипт не удалось прочитать, эмулятор завершается с кодом 2.

## Запуск и тесты

```sh
./run.sh        # Linux/macOS
run.bat         # Windows
make test       # тесты (unittest)
./run.sh --vfs examples/vfs/myfs.xml --script examples/scripts/stage2.txt
```

Скрипты ОС для проверки параметров: `scripts/test_params.sh`,
`scripts/test_errors.sh`.

## Пример

```
vfs:/$ ls -l "my docs"
ls: аргументы ['-l', 'my docs']
vfs:/$ cd a b
ошибка: cd: слишком много аргументов
vfs:/$ foo
ошибка: foo: команда не найдена
vfs:/$ exit
```
