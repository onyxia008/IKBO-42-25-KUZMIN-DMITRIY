# Эмулятор командной оболочки (вариант 17)

Учебный эмулятор командной строки UNIX-подобной ОС на Python 3.10+.
Дисциплина «Конфигурационное управление», РТУ МИРЭА.

Эмулятор работает с виртуальной файловой системой (VFS), загружаемой
из XML-файла. Все изменения VFS выполняются только в памяти — исходный
файл никогда не изменяется. Внешние зависимости не нужны.

## 1. Общее описание

| Этап | Что реализовано | Тег |
|---|---|---|
| 1. REPL | приглашение с именем VFS, парсер с кавычками, ошибки, заглушки `ls`/`cd`, `exit` | `stage-1` |
| 2. Конфигурация | параметры `--vfs`, `--script`, отладочный вывод, стартовый скрипт | `stage-2` |
| 3. VFS | загрузка из XML, base64 для двоичных данных, ошибки загрузки | `stage-3` |
| 4. Основные команды | `ls`, `cd`, `cal`, `echo`, `whoami` | `stage-4` |
| 5. Доп. команды | `touch`, `help` | `stage-5` |

Структура проекта:

```
src/emulator/
  __main__.py   точка входа, запуск по параметрам
  config.py     разбор параметров командной строки
  parser.py     разбор строки на аргументы (кавычки, экранирование)
  shell.py      REPL, выполнение команд и стартовых скриптов
  commands.py   встроенные команды
  cal.py        форматирование календаря
  vfs.py        модель VFS и загрузка из XML
  errors.py     исключения
tests/          модульные тесты (unittest)
examples/vfs/   примеры VFS (корректные и invalid/)
examples/scripts/  стартовые скрипты эмулятора для этапов 2–5
scripts/        скрипты ОС для проверки эмулятора
```

## 2. Функции и настройки

### Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--vfs PATH` | путь к XML-файлу VFS (без него — пустая VFS `vfs`) |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

При запуске выводятся все заданные параметры (`[debug]`).

Коды завершения: `0` — норма (или код из `exit N`), `2` — ошибка
параметров или стартовый скрипт не прочитан, `3` — ошибка загрузки VFS.

### Приглашение и парсер

Приглашение содержит имя VFS и текущий каталог: `deep:/home/user$`.

Парсер работает по правилам UNIX-оболочки:

- `"двойные кавычки"` — внутри экранируются только `\"` и `\\`;
- `'одинарные кавычки'` — всё буквально;
- `\` вне кавычек экранирует любой символ (`my\ dir`);
- `""` — пустой аргумент, `a"b c"` — один аргумент `ab c`;
- незакрытая кавычка — ошибка.

### Стартовый скрипт

Команды выполняются по очереди, на экране видны приглашение, ввод
и вывод. Ошибочные строки пропускаются с сообщением о номере строки,
в конце выводится число ошибок. Пустые строки и строки с `#`
игнорируются. Если скрипт не завершился `exit`, эмулятор переходит
в интерактивный режим.

### Команды

| Команда | Описание |
|---|---|
| `ls [-l] [путь ...]` | содержимое каталога; `-l` — тип, размер, время; для файла — его имя |
| `cd [путь]` | смена каталога; поддерживаются `.`, `..`, `~`; без аргумента — корень |
| `cal` | календарь на текущий месяц |
| `cal год` / `cal месяц год` | календарь на год / на месяц (неделя с понедельника) |
| `echo [текст ...]` | вывести аргументы через пробел |
| `whoami` | имя пользователя реальной ОС |
| `touch файл [файл ...]` | создать пустой файл или обновить время (в памяти) |
| `help [команда]` | список команд или справка по одной |
| `exit [код]` | выход с кодом |
| `vfs-info` | служебная: имя, источник и размер VFS |

Ошибки (неизвестная команда, неверные аргументы, несуществующий путь,
путь через файл и т. п.) выводятся с префиксом `ошибка:`.

### Формат VFS

```xml
<vfs name="demo">
  <dir name="home">
    <file name="note.txt">текст</file>
    <file name="logo.bin" encoding="base64">iVBORw0KGgo=</file>
  </dir>
</vfs>
```

- корень — `<vfs>`, атрибут `name` — имя VFS (иначе имя файла);
- `<dir>` — каталог, `<file>` — файл, атрибут `name` обязателен;
- `encoding="text"` (по умолчанию) или `encoding="base64"`;
- ошибки загрузки: файл не найден, неверный XML, неизвестный элемент,
  повтор имени, недопустимое имя, некорректный base64.

Примеры: `minimal.xml` (пустой корень), `multi.xml` (несколько файлов),
`deep.xml` (до 6 уровней вложенности), ошибочные — `invalid/`.

## 3. Сборка, запуск и тесты

Сборка не требуется, нужен Python 3.10+.

```sh
./run.sh                                  # Linux/macOS, интерактивно
run.bat                                   # Windows
./run.sh --vfs examples/vfs/deep.xml      # с VFS
./run.sh --vfs examples/vfs/deep.xml --script examples/scripts/stage5.txt
make test                                 # модульные тесты
sh scripts/test_all.sh                    # все проверочные скрипты
```

| Скрипт ОС | Что проверяет |
|---|---|
| `scripts/test_params.sh` | все комбинации параметров (этап 2) |
| `scripts/test_errors.sh` | ошибки параметров и скрипта (этап 2) |
| `scripts/test_vfs.sh` | разные VFS и ошибки загрузки (этап 3) |
| `scripts/test_commands.sh` | основные команды (этап 4) |
| `scripts/test_extra.sh` | `touch`, `help`, неизменность файла VFS (этап 5) |
| `scripts/test_all.sh` | всё сразу + unittest |
