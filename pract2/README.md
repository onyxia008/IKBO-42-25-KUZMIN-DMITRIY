# Эмулятор командной оболочки (вариант 17)

Учебный эмулятор командной строки UNIX-подобной ОС.
Дисциплина «Конфигурационное управление», РТУ МИРЭА.

## Возможности

- интерактивный режим (REPL), приглашение содержит имя VFS: `vfs:/$`;
- парсер аргументов с поддержкой `'одинарных'`, `"двойных"` кавычек
  и экранирования `\`;
- сообщения об ошибках: неизвестная команда, неверные аргументы,
  незакрытая кавычка;
- команды `ls [-l] [путь ...]`, `cd [путь]` для работы с VFS;
- команды `cal [[месяц] год]`, `echo [текст ...]`, `whoami`;
- `exit [код]` — выход из эмулятора;
- параметры командной строки `--vfs PATH`, `--script PATH`
  с отладочным выводом при запуске;
- стартовый скрипт: команды выполняются по очереди, на экране
  видны ввод и вывод, ошибочные строки пропускаются
  (пустые строки и строки с `#` игнорируются).

## Параметры

| Параметр | Назначение |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help` | справка |

Если скрипт не удалось прочитать, эмулятор завершается с кодом 2.

## VFS

Источник VFS — XML-файл. Все операции выполняются в памяти,
исходный файл не изменяется. Двоичные данные хранятся в base64.

```xml
<vfs name="demo">
  <dir name="home">
    <file name="note.txt">текст</file>
    <file name="logo.bin" encoding="base64">iVBORw0KGgo=</file>
  </dir>
</vfs>
```

Имя VFS (атрибут `name`, иначе имя файла) показывается в приглашении.
При ошибке загрузки (файл не найден, неверный XML или структура)
эмулятор сообщает об ошибке и завершается с кодом 3.
Служебная команда `vfs-info` выводит сведения о загруженной VFS.

Примеры: `examples/vfs/minimal.xml`, `multi.xml`, `deep.xml`,
ошибочные — `examples/vfs/invalid/`. Проверка: `scripts/test_vfs.sh`.

Основные команды проверяются скриптом `scripts/test_commands.sh`
(стартовый скрипт `examples/scripts/stage4.txt`).

## Запуск и тесты

```sh
./run.sh        # Linux/macOS
run.bat         # Windows
make test       # тесты (unittest)
./run.sh --vfs examples/vfs/deep.xml --script examples/scripts/stage2.txt
```

Скрипты ОС для проверки параметров: `scripts/test_params.sh`,
`scripts/test_errors.sh`.

## Пример

```
vfs:/$ ls -l "my docs"
ls: аргументы ['-l', 'my docs']
vfs:/$ cd a b
ошибка: cd: слишком много аргументов
vfs:/$ foo
ошибка: foo: команда не найдена
vfs:/$ exit
```
